# NLP_Chatbot – Rock-Paper-Scissors RAG

Lightweight, fully local RAG chatbot about pierre-feuille-ciseaux. Uses a QA pipeline (DistilBERT) with a small embedding model and Chroma vector store. Runs via Streamlit.

## Structure
- `app.py` – Streamlit UI.
- `src/ingest.py` – load `data/` and build Chroma store in `vector_db/`.
- `src/retriever.py` – create retriever over the persisted store.
- `src/llm_pipeline.py` – QA wrapper over `distilbert-base-uncased-distilled-squad`.
- `data/` – domain knowledge (history, strategies). Add more `.txt`/`.md` files to enrich the bot.
- `vector_db/` – generated by `ingest.py` (not versioned by default).

## Quickstart
1) Install dependencies (CPU-friendly):
```bash
pip install -r requirements.txt
```
2) Ingest data into Chroma:
```bash
python -m src.ingest
```
3) Launch the UI:
```bash
streamlit run app.py
```

## Notes
- Models download once to the local Hugging Face cache; set `HF_HOME` if you want a custom location.
- To customize data, drop new `.txt` or `.md` files in `data/` and rerun ingestion.
- The QA model returns concise answers; add more context to `data/` for richer responses.

# Stratégies pierre-feuille-ciseaux

- Alterner les coups pour rester imprévisible, mais introduire des motifs faux pour piéger un adversaire observateur.
- Observer les biais : débutants ouvrent souvent avec « pierre », d'autres répètent un coup après une victoire.
- Utiliser des séquences préparées (ex. pierre → ciseaux → feuille) puis changer dès que l'adversaire s'adapte.
- En tournoi, noter mentalement les tendances adverses : répétition après gain, compensation après perte, ou cycle fixe.
- Rester rapide et confiant : le tempo influence les décisions impulsives de l'adversaire.
